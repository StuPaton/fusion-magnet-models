# Fusion magnet models
Self-built models of HTS fusion magnet physics: 1D / 2D quench propagation and detection in REBCO coils, and current lead optimisation, validated against published results.

![Temperature evolution in a REBCO pancake coil](hts_quench_modelling/figures/coil_temperature_evolution.gif)

## Projects

| Project | Overview | Tools |
|---|---|---|
| [HTS quench modelling](hts_quench_modelling/) | 1D and 2D thermal quench propagation in an insulated REBCO pancake coil, including minimum quench energy, propagation velocity, and simple detection times | Python |
| [Current lead optimisation](current_lead_optimisation/) | Optimal shape of gas-cooled and conduction-cooled copper current leads to minimise heat leak, and sensitivity to excess current | Excel |
